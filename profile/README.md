# Nows MC

Nows MC is a team building tools for Minecraft Java, led by **TamKungZ_**.

## Announcement

Nows MC is now an independent team, separate from the Nows Loader product.

Until now, "Nows" referred to a single project, the Nows mod loader. As our work grew beyond the loader, keeping one name for both the team and the product became confusing. From now on:

* **Nows MC** is the team. It builds and maintains our projects and is where new ones will start.
* **Nows Loader** is a product made by Nows MC. It keeps its own identity, repositories, and website.

Nothing about how Nows Loader works changes with this announcement. What changes is the naming and the domains.

## Projects

* [**Nows Loader**](https://loader.nows.space/) - an experimental Minecraft Java mod loader. It provides a wrapper layer between mods and Minecraft, with version-specific adapters handling differences between Minecraft versions. It does not hide the Minecraft API, so mods can still use Minecraft classes, mixins, and version-specific code directly when needed.
* [**Tube**](https://tube.nows.space/) - our Minecraft server launcher.
