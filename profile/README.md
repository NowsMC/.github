# Nows MC

Nows MC is an experimental Minecraft Java mod loader maintained by **TamKungZ_**.

It provides a wrapper layer between mods and Minecraft, with version-specific adapters handling differences between Minecraft versions.

Nows does not aim to hide the Minecraft API. Mods can still use Minecraft classes, mixins, and version-specific code directly when needed.

## Projects

This organization hosts the projects and tooling around Nows MC, including the loader, version adapters, APIs, and related development tools.
